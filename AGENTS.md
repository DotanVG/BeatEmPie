# AGENTS.md

This file provides guidance to WARP (warp.dev) when working with code in this repository.

## Project Overview

**BeatEmPie** is a 2D beat-em-up Unity project (currently in early/empty state — no gameplay scripts exist yet). The concept: Shushki fights fish and whales with pies.

## Unity Version

- Unity Editor: check `ProjectSettings/ProjectVersion.txt` for exact version.
- Input: `Assets/InputSystem_Actions.inputactions` is the only asset present (generated default Input System actions).

## Status

The project contains only a default `SampleScene` and the auto-generated Input System actions. No C# scripts, prefabs, or sprites have been added yet.

## Building & Running

Open via Unity Hub → Add → select the `BeatEmPie/` directory. Press Play in the Unity Editor to run the empty scene.
